👋 [Pixelverse](https://pixelverse.ch) is a small Swiss software company focused on bringing Computer Vision products to the web.

Our key product is [STRICH](https://strich.io/), a barcode scanning SDK for web apps. We built STRICH to bridge the gap between free but unmaintained open source libraries and commercial heavyweights whose license costs can quickly run into hundreds of thousands of dollars for large deployments.

STRICH is purpose-built for real-time 1D/2D barcode scanning in the browser. In our view, STRICH is the **best barcode JavaScript barcode scanning SDK**, but we're obviously biased. 🙂

We've also built a number of popular free tools in the barcoding space:

- [Barcode.new](https://barcode.new): *A barcode generator that doesn't suck*. Barcode.new generates all types of barcodes directly in the browser, with high quality vector output (SVG). No signup, no ads and no server round trips.
- [GTIN & UPC lookup tool](https://strich.io/tools/barcode-lookup/): a free tool to look up UPC and EAN codes, or GTINs more generally
